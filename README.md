# Miller Real Estate Network — Website

## Deployment: GitHub Pages

### Step 1: Create a new repository
1. Go to [github.com/new](https://github.com/new)
2. Name it exactly: `millerrealestatenetwork.github.io`
3. Set it to **Public**
4. Check **Add a README file**
5. Click **Create repository**

### Step 2: Upload all files
1. In your new repo, click **Add file** → **Upload files**
2. Drag ALL files from this zip into the upload area (index.html, about.html, faq.html, cash-offers.html, contact.html, styles.css, robots.txt, sitemap.xml, CNAME, and the img/ folder)
3. Click **Commit changes**

### Step 3: Enable GitHub Pages
1. Go to **Settings** → **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Under **Branch**, select **main** and **/ (root)**
4. Click **Save**

### Step 4: Wait ~60 seconds
Your site will be live at: **https://millerrealestatenetwork.github.io**
